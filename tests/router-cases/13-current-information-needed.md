# Router Case — Needs Current Information

## Setup

- Mode: `guide`.
- Language: English.

## Input

> What changed in EU AI regulation this year, and how should it affect our product roadmap?

## Expected routing

`web-research-synthesis` (057) followed by `decision-memo` (069) or `executive-brief` (070). State that verification is needed and ask whether the user grants browsing permission or supplies links.

## Expected questions

1. "May I browse current sources, or do you have specific links/files?"
2. "Which decision will the synthesis feed?"

## Failure conditions

- Inventing recent regulation changes.
- Producing an opinion without sources.
- Skipping the verification step.
