# Router Case — Vague Product Idea

## Setup

- Mode: `guide` (default).
- Language: English.

## Input

> I want to create an online product but I do not know if people would buy it.

## Expected routing

Start with `customer-persona` (031) or `product-idea-validation` (038). Ask for the intended customer and problem before proposing a full launch plan.

If the user names a specific idea, follow the `validate-a-business-idea` playbook.

## Expected questions

1. "Who is the offer for, and what problem does it solve?"
2. "What evidence do you have that this problem exists today?"

## Failure conditions

- Producing a sales page immediately.
- Inventing a customer segment.
- Asking more than two questions in one turn.
- Suggesting pricing without validation.

## Notes

Common first mistake: jumping to pricing or sales-page because the user said "product".
