# Workflow Case — Competitor Analysis

## Setup

- Mode: `guide`.
- Workflow: `competitor-analysis` (034).

## Input

- Offer: An AI note-taking app for individual consultants.
- Customer: solo consultants in client-services work.
- Market: productivity software.
- Known competitors: 3 named apps (to be supplied by the user).

## Expected output

A comparison table (audience, features, pricing, messaging, strengths/weaknesses), positioning quadrant, and a gaps section.

## Verification

- Table includes the user's named competitors.
- Indirect and substitute alternatives are addressed.
- Gaps section is concrete (e.g., "no competitor offers per-client export").
- The user-provided comparison axes are honored.

## Failure conditions

- Ignoring the user-supplied competitor list.
- Producing only a feature list (no positioning).
- Skipping the gaps section.
