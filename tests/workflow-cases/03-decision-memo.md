# Workflow Case — Decision Memo

## Setup

- Mode: `guide`.
- Workflow: `decision-memo` (069).

## Input

- Decision: should we acquire a small competitor?
- Options: A) acquire, B) build, C) partner
- Criteria: speed, integration risk, cost, strategic fit
- Evidence: a 5-page due diligence summary

## Expected output

A 1–2 page memo with:

- Decision statement
- Criteria (weighted)
- Options considered
- Recommendation with conditions
- Trade-offs
- Next steps
- Verification gaps

## Verification

- Each criterion is weighted.
- At least one alternative is recommended alongside the chosen option.
- Trade-offs are explicit.
- Verification gaps are listed (e.g., financial DD outstanding).

## Failure conditions

- Producing a recommendation without criteria.
- Skipping trade-offs.
- Treating DD as complete.
