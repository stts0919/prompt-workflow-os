# Workflow Case — Article Outline

## Setup

- Mode: `quick`.
- Workflow: `article-outline` (006).

## Input

- Topic: how to choose a CRM for a 10-person startup.
- Audience: founders at early-stage B2B SaaS companies.
- Key points to include: cost vs. value, integration risk, switching cost.
- Target length: 1,200 words.

## Expected output

A hierarchical outline with H2/H3 sections, a one-line job per section, source placeholders where factual claims live, and a draft opening hook.

## Verification

- Outline covers cost, integration, and switching-cost angles.
- Section beats show logic flow (criteria → options → recommendation).
- Source placeholders are explicit.
- Opening hook mentions the audience pain in the first sentence.

## Failure conditions

- Producing a draft instead of an outline.
- Skipping source placeholders.
- Forgetting the audience framing.
