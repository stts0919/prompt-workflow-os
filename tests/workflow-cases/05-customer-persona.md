# Workflow Case — Customer Persona

## Setup

- Mode: `guide`.
- Workflow: `customer-persona` (031).

## Input

- Product: An AI-powered note-taking app for individual consultants.
- Existing signals: 200 paying customers; sales calls note "we use it for client meeting notes".
- Market: individual consultants and very small consulting firms.

## Expected output

A persona card with:

- Demographics (role, seniority, geography).
- Jobs-to-be-done.
- Pains (time, organization, recall).
- Gains (less admin, better client outcomes).
- An anti-persona.
- Verification against the existing signals.

## Verification

- Persona is concrete enough to brief a copywriter.
- Anti-persona is realistic.
- Verification log links claims to the supplied signals.

## Failure conditions

- Producing a generic "knowledge worker" persona.
- Forgetting the anti-persona.
- Inventing metrics not supported by the signals.
