# Term Glossary — `ko-KR` (Korean — South Korea)

> Source-of-truth file for the `ko-KR` term glossary. Lives under
> `shared/locales/ko-KR/` per the architecture in
> [`../README.md`](../README.md).

Context-sensitive guidance, not blind replacement. Use to pick the
Korean form when the audience is Korean. User preference, brand names,
industry vocabulary always override defaults.

10 categories, ~50 entries. Smaller than Chinese / Japanese locale
packs because the glossary focuses on loanword handling and KR-specific
business / channel terms.

## How to use this glossary

1. Detect the audience. If the user named South Korea or used Korean
   conventions, use this glossary.
2. Apply the substitution only to unprotected prose (see writing rules D).

## Limits

- This glossary does **not** translate brand names (Apple, Google,
  Microsoft, NVIDIA stay in English).
- This glossary does **not** translate workflow IDs or code identifiers.
- This glossary is a starting point, not exhaustive.

## How to extend

When adding a term:

1. Verify the Korean form by consulting at least one KR-published
   reference (표준 한국어 대사전, 국립국어원).
2. Add the Japan / China form for cross-reference.
3. Keep brand names in their official form.
4. Update both `shared/locales/ko-KR/TERM_GLOSSARY.md` and the
   canonical map.
