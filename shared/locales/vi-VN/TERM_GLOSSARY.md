# Term Glossary — `vi-VN` (Vietnamese — Vietnam)

> Source-of-truth file for the `vi-VN` term glossary. Lives under
> `shared/locales/vi-VN/` per the architecture in
> [`../README.md`](../README.md).

Context-sensitive guidance, not blind replacement. Use to pick the
Vietnamese form when the audience is Vietnamese. User preference,
brand names, industry vocabulary always override defaults.

10 categories, ~40 entries.

## How to use this glossary

1. Detect the audience. If the user named Vietnam or used Vietnamese
   conventions, use this glossary.
2. Apply the substitution only to unprotected prose (see writing rules D).

## Limits

- This glossary does **not** translate brand names.
- This glossary does **not** translate workflow IDs or code identifiers.
- This glossary is a starting point, not exhaustive.

## How to extend

When adding a term:

1. Verify the Vietnamese form by consulting at least one VN-published
   reference (Quy tắc đặt câu tiếng Việt, Ngữ pháp tiếng Việt).
2. Add the China / Japan form for cross-reference.
3. Keep brand names in their official form (often without diacritics
   for Vietnamese brands).
4. Update both `shared/locales/vi-VN/TERM_GLOSSARY.md` and the
   canonical map.
