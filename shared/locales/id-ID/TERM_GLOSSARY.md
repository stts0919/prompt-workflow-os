# Term Glossary — `id-ID` (Indonesian — Indonesia)

> Source-of-truth file for the `id-ID` term glossary. Lives under
> `shared/locales/id-ID/` per the architecture in
> [`../README.md`](../README.md).

Context-sensitive guidance, not blind replacement. Use to pick the
Indonesian form when the audience is Indonesian. User preference,
brand names, industry vocabulary always override defaults.

10 categories, ~50 entries.

## How to use this glossary

1. Detect the audience. If the user named Indonesia or used Indonesian
   conventions, use this glossary.
2. Apply the substitution only to unprotected prose (see writing rules D).

## Limits

- This glossary does **not** translate brand names.
- This glossary does **not** translate workflow IDs or code identifiers.
- This glossary is a starting point, not exhaustive.

## How to extend

When adding a term:

1. Verify the Indonesian form by consulting at least one ID-published
   reference (KBBI, PUEBI).
2. Add the Malaysia / Singapore form for cross-reference.
3. Keep brand names in their official form.
4. Update both `shared/locales/id-ID/TERM_GLOSSARY.md` and the
   canonical map.
