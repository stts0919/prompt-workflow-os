# Term Glossary — `yue-Hant-HK` (Traditional Chinese — Hong Kong)

> Source-of-truth file for the `yue-Hant-HK` term glossary. Lives under
> `shared/locales/yue-Hant-HK/` per the architecture in
> [`../README.md`](../README.md).

Context-sensitive guidance, not blind replacement. Use to pick the HK
term when the audience is Hong Kong readers. User preference, brand
names, industry vocabulary, and required regulated wording always
override defaults.

12 categories, ~60 entries. Smaller than `zh-TW` / `zh-CN` because most
HK terminology overlaps with one of the two; the table below lists
HK-specific or HK-preferred forms.

## How to use this glossary

1. Detect the audience. If the user named Hong Kong (or Cantonese
   vocabulary is in the input), use this glossary.
2. Detect the channel. WhatsApp / Facebook / LIHKG / formal email each
   have different conventions (see [STYLE_PROFILES.md](STYLE_PROFILES.md)).
3. Detect the user-recorded terms. If the user wrote a specific term
   (e.g. 「軟件」), keep that term.
4. Apply the substitution only to unprotected prose (see writing rules D).

## Limits

- This glossary does **not** claim to translate brand names (Apple,
  Google, Microsoft stay in English; HK Cantonese 「蘋果」「谷歌」are
  rare).
- This glossary does **not** translate workflow IDs or code identifiers.
- This glossary is a starting point, not exhaustive.

## How to extend

When adding a term:

1. Verify the HK form by consulting at least one HK-published reference
   (HK Govt Education Bureau materials, RTHK style guides, public Cantonese
   grammar resources).
2. Add the Taiwan / Mainland form for cross-reference.
3. Keep brand names in their official form.
4. Update both `shared/locales/yue-Hant-HK/TERM_GLOSSARY.md` and the
   canonical map.
