# Taiwan Traditional Chinese Term Glossary

This glossary is a reference for the Taiwan localization layer. It is **not** a rigid replacement engine. Context, user preference, target market, brand names, industry vocabulary, and required regulated wording all override the defaults listed here.

When a glossary entry is uncertain, ask the user. When the user supplied their own wording, use it consistently and record it in the context ledger.

Each row has six fields:

- **Concept** — what the term is for in plain English.
- **Preferred zh-TW** — the default Taiwan wording in most contexts.
- **Acceptable alternatives** — variants that are also fine.
- **Avoid by default** — the form to avoid unless the context demands it.
- **Context notes** — when the choice changes.
- **Example** — a minimal example showing the term in use.

The glossary is organized into 13 categories.

## How to use this glossary

1. **Detect language first.** When the user writes in any Chinese variant, identify whether they specified locale. Default to Taiwan unless they specified another.
2. **Apply only context-appropriate substitutions.** Many substitutions are wrong out of context. For example, 「登入」與「登錄」在台灣都讀作 `dēng rù`，但 UI 慣用「登入」。
3. **Respect user override.** If the user says「我們都用『登錄』」，record it in the context ledger and use it consistently for that user's session.
4. **Do not translate protected content.** Skip glossary substitution for code, IDs, URLs, brand names, required disclosures.
5. **When in doubt, ask once.** A single clarification beats a forced substitution that breaks the user's voice.

## Limits

- This glossary does not claim coverage of all Taiwan or all Chinese variants. New terms appear regularly.
- Entries here do not represent a Microsoft / Apple / Google house style. Brand-specific spellings should follow the brand's published localization.
- Some entries reflect common industry usage rather than a single authoritative source.
- The finance / metrics section covers commonly used SaaS metrics. Domain-specific finance (banking, insurance, capital markets) is out of scope.
