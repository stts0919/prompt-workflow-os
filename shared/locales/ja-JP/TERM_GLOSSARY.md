# Term Glossary — `ja-JP` (Japanese — Japan)

> Source-of-truth file for the `ja-JP` term glossary. Lives under
> `shared/locales/ja-JP/` per the architecture in
> [`../README.md`](../README.md).

Context-sensitive guidance, not blind replacement. Use to pick the
Japanese form when the audience is Japanese. User preference, brand
names, industry vocabulary always override defaults.

10 categories, ~50 entries. Smaller than Chinese locale packs because
the glossary focuses on loanword handling and JP-specific business /
channel terms; general Japanese vocabulary is not catalogued.

## How to use this glossary

1. Detect the audience. If the user named Japan or used Japanese
   conventions, use this glossary.
2. Apply the substitution only to unprotected prose (see writing rules D).

## Limits

- This glossary does **not** translate brand names (Apple, Google,
  Microsoft, NVIDIA stay in English).
- This glossary does **not** translate workflow IDs or code identifiers.
- This glossary is a starting point, not exhaustive.

## How to extend

When adding a term:

1. Verify the Japanese form by consulting at least one JP-published
   reference (NHK 放送用語, 共同通信社 表記Guidelines, 産業用語辞典).
2. Add the China / Taiwan / HK form for cross-reference.
3. Keep brand names in their official form.
4. Update both `shared/locales/ja-JP/TERM_GLOSSARY.md` and the
   canonical map.
