# Start Here

> If this is your first time using the repository, read this page before anything else.

## What this repository is

A Markdown-first library of 100 prompt workflows plus a router, playbooks, shared rules, templates, and evaluation cases. The user never has to memorize a workflow name. The router infers intent and selects the smallest sufficient workflow chain.

## 60-second onboarding

1. Share the repository with an AI that can read files.
2. Tell it to read [../START.md](../START.md).
3. Describe what you want in natural language.
4. Answer 1–2 questions, then receive the result.

For verbose guidance see [../START.md](../START.md) and [../README.md](../README.md).

## Browse paths

- [By output](04-by-output.md) — when you know the artifact you need.
- [All 100](05-all-100-workflows.md) — the complete list.

## Three modes

- **Guide me** — step-by-step discovery, confirm before each major move.
- **Quick mode** — execute with labeled assumptions when risk is low.
- **Recommend** — propose a workflow chain before starting.
