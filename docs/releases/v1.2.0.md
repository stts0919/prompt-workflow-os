# v1.2.0 — All 9 locale packs live

**Released:** 2026-09-22
**Tag:** `v1.2.0` (commit `68fc757`)
**Type:** Minor (new locale packs; backward-compatible)

## What's in this release

`prompt-workflow-os` now ships **9 locale packs** total. Every pack
follows the same structural rigor: 4 content files (WRITING_RULES,
TERM_GLOSSARY, STYLE_PROFILES, QUALITY_CHECKLIST) + README, sitting
under `shared/locales/<code>/`.

| Locale | Code | Shipped in | Highlights |

## Router coverage

`router/ROUTING_RULES.md` gains three new locale sections in v1.2.0:

- **§1.7** — `yue-Hant-HK` activation rules and style profile selection
- **§1.8** — `en-US` / `en-GB` activation rules
- **§1.9** — `ja-JP` / `ko-KR` / `id-ID` / `vi-VN` activation rules

The harness (`tests/_evaluations/prompt_builder.py`) `LANGUAGE_FILES`
map now points at all 9 packs. The router activates the right layer
automatically based on the case's `expected_locale` field.

## Upgrade notes

- **No breaking changes.** All workflow IDs and slugs remain stable.
- The `localization:` frontmatter block is **optional**. 41 high-traffic
  workflows carry it explicitly; the other 59 inherit the category
  default documented in `templates/WORKFLOW_TEMPLATE.md`.
- New locale packs are pure additions; they activate only when the case
  / request triggers them.

## What did NOT change

- The 100-workflow structure (`29 + 24 + 18 + 17 + 12 = 100`, IDs `001`–`100`)
- The two-layer workflow format
- The 5 router files, 3 templates, 5 playbooks, 6 indexes
- The 5 base shared rules
- The editing intensity model (`none` / `light` / `standard` /
  `strict_precision`) remains per-workflow with router auto-escalation
