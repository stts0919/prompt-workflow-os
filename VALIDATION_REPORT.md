## Limitations

The validator checks structure, not correctness. A workflow may have every required field and still be wrong. To prove correctness:

1. Run the evaluation cases in `tests/router-cases/`, `tests/language-cases/`, and `tests/workflow-cases/` against an AI model with the repository attached.
2. Score outcomes against each case's `Expected routing` / `Expected output` / `Failure conditions`.
3. Track results in a separate evaluation log.
